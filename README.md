## 🛡️ CyberShield SOC Dashboard

CyberShield is a real-time Security Operations Center (SOC) dashboard built using **React**.
It simulates a live cyber threat intelligence monitoring platform with interactive visualizations and security tools.

## 🚀 Project Overview

CyberShield simulates real-time threat monitoring by generating procedural cyber attack data inspired by platforms like:

* AbuseIPDB
* Feodo Tracker
* Emerging Threats
* CINS Score
* Spamhaus DROP

The dashboard refreshes automatically every **2.8 seconds**.

## 📊 Features (10 Functional Modules)

### 1️⃣ Dashboard

* Live KPI counters
* Severity breakdown chart
* API source distribution
* Attack type analysis
* Real-time threat feed

### 2️⃣ Threat Map

* Animated SVG world map
* Global attack visualization
* Country-based threat simulation

### 3️⃣ Analytics

* Bandwidth history graph
* Threat severity timeline
* API ranking chart
* Dynamic Security Score gauge

### 4️⃣ AI Assistant

* Cybersecurity chatbot
* Answers about:

  * Phishing
  * DDoS
  * Ransomware
  * SQL Injection
  * Firewalls

### 5️⃣ URL Scanner

* Risk scoring
* SSL validation
* Malware detection
* Phishing check
* Reputation analysis

### 6️⃣ Threat History

* Filterable logs
* Severity filtering
* IP & attack display
* MITRE ATT&CK IDs

### 7️⃣ Database Module

* Mock SQLite manager
* Connect / Disconnect toggle
* Live SQL query runner
* Results table

### 8️⃣ Export Data

* One-click CSV export
* Threat feed export
* API summary export

### 9️⃣ Barcode Scanner

* Phishing redirect detection
* Counterfeit detection
* Domain analysis

* Device discovery
* IP & MAC display
